# v0.1.0 发布方案

本文是发布方案，不代表发行包已经公开。Windows 源码已进入 `main`；截至 2026-10-13 尚无版本标签或正式 Release。目标交付 Windows 本地桌面应用的源码仓库与可安装源码包。用户安装 Python 3.11 后运行安装脚本，再启动桌面界面。GitHub 负责源码、自动检查和发行包分发；安卓伴侣、公网多用户服务、免 Python 的 EXE 与模型打包不包含在当前公开源码范围。

## 实施顺序

1. 建立有效 Git 仓库，主分支为 `main`；保留本机配置、历史及登录状态。
2. 采用 MIT 源码许可证，保留第三方授权说明；不分发私人资料、角色图片、下载媒体或模型权重。
3. 统一版本号为 `VERSION`，补齐安装脚本、启动失败提示、环境诊断、故障排查与卸载说明。
4. 固定 Windows/Python 3.11 的运行与开发依赖，并在独立环境验证安装和全部回归。
5. 建立发布检查：从 Git 中读取实际提交内容，拦截私人目录、非示例配置、疑似凭证、符号链接和超大文件。发现问题仅输出文件及规则，不回显秘密。
6. 验证干净源码副本：空关注启动、页面与 API、Python 回归、前端回归、依赖一致性和 PowerShell 语法。
7. 生成 `cyber-intelligence-agency-0.1.0-source.zip`、SHA256 校验文件与记录提交号的构建清单；压缩包只包含提交中的源码。
8. 增加 CI、依赖更新、问题模板、贡献指南、安全报告和变更日志；版本标签触发完整检查与 GitHub 草稿 Release。
9. 创建本地发布提交与 `v0.1.0` 标签，保存验证结果。远端地址明确且具有推送权限时再上传；首次远端检查通过后发布草稿 Release。

## 验收条件

- 全部自动测试通过，Windows 安装过程可以重复运行且不覆盖已有个人设置。
- 没有 API Key 的新安装能够打开页面、查看空关注列表和进入设置。
- 源码包不包含任何真实账号、接口配置、Cookie、简报、历史或权重。
- 版本、标签、压缩包、SHA256 与构建清单互相对应。
- GitHub 工作流只对标签发布任务授予写权限，不对 Pull Request 授予凭证或发布权限。
- 文档明确模型需按需下载、AI 可能收费、桌面凭证绑定 Windows 用户，以及本版本的实际支持范围。

## 发布后的维护

通过 Issue 收集可复现错误；修改附带相关回归验证。依赖更新在 CI 通过后合并，并重新验证锁定文件。每个版本更新 `VERSION` 和 `CHANGELOG.md`，按 `docs/RELEASING.md` 发布。真实平台扫码、AI 调用与 Windows 通知需要维护者在自己的运行环境检查，不由 CI 代替。
