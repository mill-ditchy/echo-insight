# 平台使用与分析设置

安装与首次配置见 [README](../README.md)，故障排查和更新见[安装与排查](TROUBLESHOOTING.md)。本文说明当前源码实现，不保证平台接口或模型持续可用。

## 平台关注与登录

| 平台 | 添加关注 | 登录方式与读取边界 |
| --- | --- | --- |
| B站 | UP 主数字 UID | “账号管理”扫码登录；优先读取可见视频和字幕，动态与投稿分页每轮有上限 |
| 知乎 | `/people/` 或 `/org/` 主页链接，也可用网址中的英文标识 | 桌面官方登录窗口保存会话；过滤点赞、关注、收藏等互动，只读取原创内容 |
| 小红书 | `/user/profile/` 博主主页链接 | 桌面官方窗口登录后保存；手机分享短链先打开并复制博主主页链接，不采集收藏、评论或私密笔记 |
| 抖音 | `/user/` 博主主页链接 | 公开页面可见时可不登录；需要时在桌面官方窗口登录保存，不构造签名接口或绕过验证 |

知乎不能用中文昵称代替网址标识。B站的 `-352`、`-412`、`-799` 等风控响应可先检查登录，再等待重试。登录已保存不代表平台已经验证可读。

本机网页可以扫码登录 B站；另外三个平台的独立登录窗口需要桌面桥接能力。网页可使用同一电脑上已保存的会话，或在添加关注时手动填写自己的 Cookie 作为备用。Cookie 等同登录凭证，不要截图分享；不再使用时可在账号管理删除保存状态。

四个直接平台首次通常显示最近 3 条，不计入未读；后续更新按内容身份去重。B站和知乎分页补抓每轮通常最多 5 页，达到预算保存位置，下次继续。小红书本轮最多扫描 120 张卡片、滚动 8 次、读取 20 条作品，读取预算约 120 秒；已发现的待补作品保存在本机。抖音增量读取最多额外滚动 5 次，并受时间、作品数量和关注边界约束。

这些上限是避免无限采集的实现边界，不是平台历史完整性的保证。没有新作品、需要登录、验证失败、网络错误和读取范围有限是不同状态，查看页面提示和原主页后再判断。

## 视频与图文简报

### B站与知乎

B站优先读取字幕并缓存；没有可用字幕时使用本地 Whisper 转写。启用画面分析时结合采样画面、OCR 和对白；无语音但视觉输入可用时限定为画面依据，全部依据不可用时不凭标题生成成功摘要。

知乎文章与视频基于读取到的公开正文、简介或字幕总结。回答、提问和想法直接展示原文。知乎视频不走 B站的视频下载与分段画面分析流程。

### 小红书与抖音

两者区分视频与图文。视频读取官方页面给出的媒体，复用本地转写、采样画面和分析流程；本版共享视频流程限制为 60 分钟、512MB 媒体和约 3 分钟下载预算。地址可能过期，需刷新原作品后重试。

图文结合正文、OCR 和可选视觉理解。小红书快速模式最多分析前 6 张，完整模式最多 30 张；抖音默认使用完整模式。长图分段读取，每批最多 6 个图片区段，一次最多 20 批新的图片理解调用。超过数量、读取失败或依据不足会提示范围有限，成功批次可复用。

列表和详情主要展示文字，图片参与后台分析，不把“采样覆盖”宣称为逐帧完整理解。可以展开原文或摘要依据，也可打开原作品核对。重新分析成功后才替换旧简报，失败保留原成功结果；模型推断和来源记录不等于事实核查。

## AI 接入

在“设置 → AI 接入”配置兼容 Chat Completions 的服务：

1. 点击“新增配置”，填写配置名称和供应商名称，再填写服务商的基础地址，例如 `https://api.example.com/v1`，或完整的 `/chat/completions` 地址；远程必须用 HTTPS，本机可用 `http://127.0.0.1:端口/v1`。
2. 填写该服务的 Key，点击“读取可用模型”，从下拉列表选择文字模型。模型名称和额度不能跨服务商假定通用。
3. 需要画面或图片理解时启用画面分析，在视觉模型下拉列表选择支持图片输入的模型；选择“与文字模型相同”时，文字模型也必须支持图片。
4. 视觉模型共用已读取的模型列表，也可选择“与文字模型相同”。切换地址或密钥后需重新读取列表；服务需提供兼容的模型列表接口。
5. 测试文字连接与所需图片输入，再保存配置。测试使用真实请求，可能计费，不会自动保存草稿，也不会切换启用项。

可保存多个供应商，以及同一供应商的不同接口、账号或模型组合，每套单独保留密钥。打开列表中的“启用”开关即可切换；同一时间启用一套，新开始的分析采用该配置。首套配置自动启用，之后新增默认只保存，也可勾选“保存后启用”。编辑当前启用项并保存后，新开始的分析会采用修改后的内容。

已有接入会作为“原有配置”保留。“复制”可沿用接口与密钥后另选模型；“编辑”用于修改该项，当前启用项需先切换到另一套才能删除。

编辑或复制时，Key 留空可保留该配置已保存的密钥；切换接口地址必须提供新服务的 Key，旧 Key 不会发送给新地址。新增配置需填写 Key，或从已有配置复制。默认地址和模型只是配置默认值，不附带密钥、免费额度或可用性承诺。

等待任务在执行时采用当时的接入与视频配置，一次尝试期间保持不变；失败重试可以采用新设置。历史结果不会因修改配置自动重算。缓存可减少重复调用，但重新分析、修复缺失片段和更改模型或资料仍可能产生费用。

未在界面保存管理配置前，保留 `DEEPSEEK_API_URL`、`DEEPSEEK_MODEL`、`DEEPSEEK_API_KEY` 等旧环境变量入口。面向新用户推荐界面配置，避免把含凭证的环境信息用于公开报告。

## 视频理解与可选资料

“设置 → 视频理解”可调整分段、采样帧、OCR 和联网资料查询。默认目标段长 20 秒、最多 10 段、每段最多 8 张画面；段数受限时拉长分段覆盖全片，短暂画面仍可能遗漏。

默认图片输入兼容范围较广。视频输入将采样画面编码为无声 MP4，通过 `video_url` 发送，要求模型服务明确支持这种输入；它不等于发送完整原始音视频。“测试画面输入方式”会实际调用已保存的模型，可能计费。

“设置 → 人物与作品资料”可以添加人物、作品、别名、说明、来源及参考图，不限定题材。资料库默认留空，不展示预置示例；不添加资料也能分析视频。OCR 以中文、英文为主；百科查询结果是有出处的候选信息，不自动成为人工资料库事实。

可选模型安装（联网并占用磁盘）：

```powershell
.\.venv\Scripts\python.exe scripts/setup_character_models.py
```

`--mirror` 可使用镜像，`--without-wd` 只安装 CCIP。这些可选模型主要用于插画角色匹配，不提供通用人物识别能力，资料文本的使用不依赖它们。`scripts/seed_character_gallery.py` 是手动导入游戏角色参考图的开发工具，应用不会自动执行；仅在需要这些资料时运行，执行前阅读[授权说明](LICENSING.md)，不要把图片随源码分发。

## 命令行与 RSS

```powershell
.\.venv\Scripts\python.exe app.py
```

按菜单添加关注、查看列表或生成 Markdown 简报。命令行使用较简单的批量流程，不等同于桌面的分页阅读与任务面板。RSS/Atom 的 UID 即订阅地址；RSSHub 路由还需独立实例，当前 `src/platforms/rsshub.py` 的默认基址为 `http://localhost:1200`，没有页面配置入口或自动部署步骤。

微博、快手、X、YouTube、微信公众号在注册表中通过 RSSHub 路由接入；平台是否支持与读取范围依赖路由和实例，不保证可用。Feed 检查覆盖当前返回的条目窗口，不能恢复已经从 Feed 消失的历史。

## 后台任务与自动检查

安装后自动抓取不会开启。在主界面启用开关会创建 Windows 计划任务，默认间隔 3 小时；关闭后停止自动检查，手动检查仍可使用。修改间隔保留开关状态。运行失败会尝试通知，默认临时失败等待 5 分钟后额外重试一次，配置、凭证、余额或证书错误不反复请求。

“设置 → 后台任务”可查看运行、等待和失败状态，取消等待任务、设置每日分析尝试上限及预览原始媒体清理。0 表示不限；重试计入次数，一次分析可能包含多次模型调用，不能据此保证费用上限。

关闭网页或桌面窗口不会必然停止已提交的独立分析进程。更新、备份和卸载前关闭自动抓取，等待任务结束；存储迁移、备份与回退见[后台任务实施记录](RELIABILITY_PLAN.md)。高级计划任务脚本 `scripts/install_scheduler.ps1` 会创建或更新系统任务，不作为普通安装的一部分。

## 本机文件

| 路径 | 用途 |
| --- | --- |
| `config/` | 个人设置、关注、凭证引用与加密凭证；`*.example.json` 仅为格式示例，应用不自动加载 |
| `data/` | SQLite 历史与任务、采集状态和迁移备份 |
| `output/` | 简报、字幕、媒体缓存、分析证据及旧摘要备份 |
| `knowledge/images/` | 用户的角色参考图 |
| `models/` | 可选模型 |

这些个人文件不应提交到 GitHub。凭证不能直接跨电脑恢复，历史与分析证据也不等同于加密数据；请按[安全说明](../SECURITY.md)保护备份。
