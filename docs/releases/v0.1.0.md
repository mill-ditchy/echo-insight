# 赛博情报局 v0.1.0

Windows 本机运行的个人情报工作台，支持 B站、知乎、小红书和抖音关注、AI 简报与未读管理，命令行可使用 RSS/RSSHub。该发行包是源码包，需要 Python 3.11 x64；无需另装 FFmpeg 命令行工具。安卓伴侣留待后续版本，本次安装不依赖安卓代码或工具。

## 安装

1. 下载 `cyber-intelligence-agency-0.1.0-source.zip` 及同名 `.sha256`，核对 `Get-FileHash -Algorithm SHA256` 的结果。
2. 解压至当前用户可写的目录，打开 PowerShell，执行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/setup.ps1`。
3. 安装 WebView2 Runtime 后双击 `启动赛博情报局.bat`，在应用中设置自己的账号和 AI 服务。

AI 调用可能产生服务商费用；模型需按需下载，账号与 Key 不包含在安装包中。已安装用户更新前备份本机 `config/`、`data/` 与所需 `output/`，保留原个人目录，不要用其他用户的凭证覆盖自己的文件。

## 本版变化

- 首次启动支持空关注，首页统计减少重复历史读取。
- 桌面窗口启动失败时完整停止本地服务。
- 安装、环境诊断、依赖锁定、发布文件检查、自动回归与校验值配齐。
- SQLite历史与持久分析队列保留全部记录、阅读状态和旧成功简报；增量采集保留补抓位置，AI阶段使用固定配置并拒绝截断结果。
- 来源详情、分页与轮询按内容身份处理；只读查询和准备/恢复命令分开，电脑端验证独立于安卓专用测试。

该版本仅为 Windows 本地应用。真实扫码、平台风控、音视频下载和 AI 模型能力仍受运行环境与服务可用性影响。公网服务与免 Python 安装包不在此版本范围内。
